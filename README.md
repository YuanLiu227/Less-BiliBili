# Less BiliBili

Less BiliBili 是一个 Manifest V3 浏览器扩展，目标是把 B 站从“被推荐流牵着走的平台”尽量拉回“主动选择观看的工具”。

它保留关注动态、个人空间、历史记录和视频播放这些主动使用路径，同时隐藏推荐、评论、弹幕、广告、热搜、分享扩散、关系跳转等容易分散注意力的入口。它不是纯播放器模式：视频页的播放器、标题、UP 信息、简介、操作栏、选集/合集、宽屏和小窗等正常观看功能会尽量保留。

## 功能概览

默认保留：

| 场景 | 保留内容 |
| --- | --- |
| 关注动态 | 查看已关注 UP 的动态更新 |
| 视频详情页 | 播放器、标题、UP 信息、视频数据、简介、操作栏、选集/合集、宽屏、小窗 |
| 个人空间 | `space.bilibili.com` 与 `www.bilibili.com/space/*` 下的 UP 信息、主页/投稿/合集、视频列表 |
| 关注列表 / 账号中心 | `account.bilibili.com` 下管理关注，并进入已关注 UP 主主页 |
| 搜索功能 | 开启时显示搜索栏，并允许进入 `search.bilibili.com` 搜索结果页 |
| 历史记录 | `www.bilibili.com/history`、`www.bilibili.com/account/history` |
| 登录相关 | `passport.bilibili.com` |

默认隐藏：

- 动态页评论区、点赞评论入口和互动提示
- 搜索热词、视频标签、分享扩散和关系跳转入口
- 首页、直播、番剧、游戏中心、会员购等顶部偏航入口
- 视频页右侧推荐、相关视频和推荐接口
- 视频页评论区
- 弹幕层、弹幕开关、弹幕输入框和弹幕列表
- 广告、活动、下载提示、直播推广、商品推广和游戏推广
- 个人空间里的关注/粉丝入口、追番追剧、直播间和游戏推广
- 播放结束后的推荐覆盖层和自动连播入口
- B 站首页和分区页默认跳转到关注动态页

## 模块开关

popup 提供快速开关；完整设置页按场景提供全部模块，每项都会独立保存。
保存后会主动同步已打开的 B 站标签页，页面内的隐藏/恢复逻辑会尽量即时生效；涉及网络拦截的推荐、热榜分享、广告推广规则变化时，会自动刷新 B 站标签页，让页面重新请求内容。

### 基础控制

| 模块 | 作用 |
| --- | --- |
| 启用扩展 | 一键暂停或恢复全部清理逻辑 |
| 首页跳到关注动态 | 访问首页或分区页时自动跳转到关注动态 |

### 视频页

| 模块 | 作用 |
| --- | --- |
| 隐藏右侧推荐 | 隐藏视频页右侧推荐、相关视频和部分推荐接口 |
| 隐藏评论区 | 隐藏视频页评论区域 |
| 隐藏弹幕 | 隐藏弹幕层、弹幕开关、输入框和弹幕列表 |
| 禁用自动连播 | 视频自然结束后不自动播放下一个内容 |
| 隐藏播放结束推荐 | 隐藏视频结束后的推荐覆盖层和更多推荐入口 |

### 关注动态

| 模块 | 作用 |
| --- | --- |
| 隐藏动态互动 | 隐藏动态评论、点赞评论入口和互动提示 |
| 开启搜索功能 | 显示搜索栏并允许进入 `search.bilibili.com` 搜索结果页；关闭后搜索页会回到关注动态 |
| 隐藏热榜和分享入口 | 隐藏热搜词、视频标签和分享扩散入口 |
| 隐藏顶部导航 | 隐藏首页、直播、番剧等容易偏离观看目标的顶部入口 |

### 推广和白名单

| 模块 | 作用 |
| --- | --- |
| 隐藏广告和推广 | 隐藏广告、活动、下载提示、直播和游戏推广 |

隐藏右侧推荐、隐藏热榜和分享入口、隐藏广告和推广分别对应独立的 DNR 网络规则集。关闭其中某个模块时，不会连带关闭其他网络拦截模块。

## 白名单

白名单用于放行某些 B 站页面。匹配白名单后，该页面不会被首页跳转处理，也不会执行内容清理。

每行一个 URL 或通配符，例如：

```text
https://www.bilibili.com/
https://www.bilibili.com/v/popular
https://www.bilibili.com/video/BV*/
```

没有 `*` 的条目按 URL 前缀匹配；包含 `*` 的条目按通配符匹配。

## 安装

1. 克隆或下载本仓库。
2. 打开浏览器扩展管理页：
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. 开启开发者模式。
4. 选择“加载已解压的扩展程序”，加载本项目目录。

## 开发与验证

静态检查：

```bash
node --check content.js
node --check background.js
node --check popup/popup.js
node --check options/options.js
node --check scripts/regression-test.js
node -e "const fs=require('fs'); for (const f of ['manifest.json','rules_recommendations.json','rules_exploration.json','rules_ads.json']) JSON.parse(fs.readFileSync(f,'utf8'))"
```

自动回归测试：

```bash
node scripts/regression-test.js
```

回归脚本会复制一份临时扩展目录，启动独立的 Edge/Chromium 测试配置，不使用你的日常浏览器配置。

## 项目结构

```text
manifest.json                 扩展配置
background.js                 后台服务，负责重定向和 DNR 规则同步
content.js                    页面脚本，负责注入样式、DOM 清理、SPA 路由处理
content.css                   与 content.js 内置样式保持同步的 CSS 源文件
rules_recommendations.json    右侧推荐网络拦截规则
rules_exploration.json        热榜和分享入口网络拦截规则
rules_ads.json                广告推广网络拦截规则
popup/                        扩展弹窗控制面板
options/                      完整设置页
scripts/                      自动化验证脚本
icons/                        扩展图标，包含浅蓝电视图标和橙色减号标识
```

## 设计原则

这个项目不替用户决定要看什么，而是把“主动选择观看”和“被推荐系统推着走”分开。

播放器本身应尽量正常；注意力干扰应明确、可控、可关闭。
