# Less BiliBili

只看关注，主动搜索。一个本地运行的 Manifest V3 浏览器扩展，把 B 站变成按需观看的工具，减少推荐流、热搜、社交反馈和自动连播带来的依赖。

## 三步上手

1. 点击扩展图标，选择 **查看关注动态**，浏览已关注 UP 的更新。
2. 想看其他内容时，在弹窗里输入关键词，直接进入搜索结果。
3. 选择视频观看。默认收起推荐、评论、弹幕和推广，播放结束后停下；仍可手动选集、切换下一条。

默认设置即可使用。弹窗只保留总开关、隐藏评论、隐藏弹幕三个开关；其他选项在 **更多设置** 中自动保存。搜索词不会保存在扩展中。

## 保留什么，收起什么

| 页面 | 保留 | 默认收起 |
| --- | --- | --- |
| 关注动态 | 关注的 UP 列表、动态正文、视频入口 | 互动反馈、热门话题、推荐 UP、直播推荐 |
| 主动搜索 | 关键词、搜索结果、排序筛选 | 热搜、搜索建议、推荐热词占位文字 |
| 视频 / 番剧播放 | 播放器、标题、UP 信息、简介、收藏、选集和手动下一条 | 相关视频、结束推荐、评论、弹幕、自动连播 |
| UP 空间 | UP 信息、投稿、合集、关注管理 | 粉丝扩散入口、追番区块、直播和游戏推广 |
| 个人工具 | 登录、账号、历史、收藏、稍后再看 | 常见广告和推广 |

首页、热门、分区等页面默认回到关注动态。没有关键词的搜索页也会回到关注动态，空搜索不会提交 B 站推荐的默认热词。关闭“首页回到关注动态”后，页面跳转限制解除。

扩展保留 B 站原生关注动态，不额外读取账号或拉取关注关系，因此不会逐条核验动态作者身份；也不会过滤 UP 自己发布的推广或转发。页面结构变化时，个别干扰入口可能需要更新选择器。

## 设置

**关注与搜索**：首页回到关注动态、允许主动搜索、隐藏推荐内容、隐藏热搜与分享、精简顶部导航、隐藏动态互动。

**观看体验**：播放结束后停下、隐藏结束推荐、隐藏评论、隐藏弹幕、隐藏广告与推广。

所有开关即时保存并同步到已打开的页面。网络规则变化影响后续请求；恢复之前被拦截的内容时，可在方便时手动刷新。修改设置不会自动刷新视频。

“恢复默认设置”会重新启用全部防干扰功能，保留已有的例外页面。

## 例外页面（原白名单）

在设置页展开 **例外页面**，每行填写一个完整 B 站网址，例如：

```text
https://www.bilibili.com/video/BV*/
https://space.bilibili.com/2/
```

不含 `*` 时匹配 URL 前缀；`*` 可用于路径或查询部分。网址会规范化并去重，忽略 `#` 后的片段。最多保存 100 条。只有 B 站网址可作为例外；填写错误时会显示提示并保留原配置。

命中例外的页面不重定向、不清理。网络放行使用浏览器规则，在下次访问或刷新后生效。填写 `https://www.bilibili.com/` 会放行这个域名下的全部页面，包括首页和热门。

## 安装 / 更新

1. 下载或克隆本项目。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
3. 开启开发者模式，选择“加载已解压的扩展程序”，选中本项目目录。

已有安装更新源码后，在扩展管理页点击“重新加载”，再刷新一次已打开的 B 站页面。旧版模块开关和合法的白名单会继续保留。

## 开发与验证

不需要安装 npm 依赖。Node.js 22+，浏览器回归需要本机 Edge 或支持加载解压扩展的 Chromium。

```bash
node scripts/unit-test.js
node scripts/regression-test.js
```

单元测试覆盖 URL 边界、主动访问路径、旧设置兼容、例外校验、并发保存和规则同步。浏览器回归使用临时扩展与独立浏览器配置，通过模拟 B 站文档验证实际扩展注入、网络规则启停、界面、播放结束拦截、搜索清理、SPA 跳转、暂停恢复及设置同步，避免依赖网站登录或网络状态。

```bash
node scripts/regression-test.js --ui-only
node scripts/regression-test.js --live
```

`--ui-only` 只检查界面；`--live` 使用真实 B 站页面，可能受登录、风控、网络或测试视频可用性影响。回归截图保存在忽略提交的 `test-artifacts/` 目录中。可用 `BILIBILI_LESS_BROWSER` 指定浏览器路径，`BILIBILI_LESS_TEST_VIDEO` 指定测试视频。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `settings.js` | 共用默认配置、URL 放行与例外匹配 |
| `settings-ui.js` | 共用界面保存与跨窗口同步 |
| `background.js` | 串行合并设置、同步网络规则与页面跳转 |
| `content.js` / `content.css` | 页面清理、播放结束拦截、SPA 处理；CSS 保持同步 |
| `popup/` | 关注、搜索、历史入口和常用开关 |
| `options/` | 完整设置与例外页面 |
| `rules_*.json` | 推荐、热搜、广告的独立网络规则 |
| `scripts/` | 单元测试、浏览器回归和模拟文档 |

扩展不增加远程服务或统计。详见 [隐私说明](./PRIVACY.md)、[修改记录](./CHANGE_SUMMARY.md) 和 [故障排查](./TROUBLESHOOTING.md)。
